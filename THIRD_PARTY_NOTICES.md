# Third-Party Notices

## yagcode-cli

The YagCode CLI packages the project-owned Python entry point and the Python runtime needed to run it without the Electron desktop app.

## yagcode-desktop

The YagCode desktop app packages the project-owned Electron/React renderer, Electron runtime, and the local Python sidecar.

## electron

Electron is used for the native desktop shell and includes Chromium and Node.js runtime components.

## react

React and ReactDOM are used for the desktop renderer UI.

## cpython

CPython is included in PyInstaller-built sidecar and CLI bundles.
